# Motor Imagery-Based Wheelchair
Neurotech@USC BCI Project for 2026-27. The goal is to extend our past work creating a motor-imagery controlled cursor into a wheelchair.

## Repo Guide: (updated 11/03/26)
`bci/` -> contains all the online experiments used in the cursor project. Use bci_orchestrator.py to run the live demo.

`ErrP/` -> use ErrP_Workflow.ipynb to replicate our ErrP processing. This file is meant to be used as a Google Colab.

`psychopy/` -> contains all the offline (data collection) experiments. The README contains instructions for participants.
